# Week 6 - Spark Assignment (PySpark)

## Project Overview

This project is part of the **Celebal Technologies Summer Internship Program – Week 6 Spark Assignment**.  
The assignment focuses on understanding Apache Spark architecture and implementing data processing operations using **PySpark DataFrames**.

The notebook covers Spark transformations, actions, schema handling, filtering, column operations, performance concepts, and CSV vs Parquet processing.

---

## Objective

The main objectives of this assignment are to:

- Understand Spark architecture and its major components.
- Learn lazy evaluation and DAG execution in Spark.
- Read and process datasets using PySpark DataFrames.
- Apply transformations such as filtering, renaming, casting, and creating columns.
- Understand transformations and actions.
- Compare CSV and Parquet file formats.
- Learn performance concepts such as predicate pushdown.
- Build a complete read → transform → filter → write pipeline.
- Understand best practices for working with large datasets.

---

## Topics Covered

1. Spark Architecture — Driver, Cluster Manager, and Executors
2. Lazy Evaluation and DAG
3. Reading CSV and Parquet files
4. Schema inference and schema handling
5. DataFrame transformations
6. Filtering rows
7. Renaming columns
8. Casting data types
9. Creating calculated columns
10. Wide transformations
11. Transformations vs Actions
12. Predicate Pushdown
13. CSV vs Parquet comparison
14. Client Mode vs Cluster Mode
15. Efficient handling of large datasets using `.show()` instead of unnecessary `.collect()`
